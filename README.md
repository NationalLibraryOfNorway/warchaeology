# warchaeology

Warchaeology is a collection of tools for inspecting, manipulating and validating WARC-files.

## Installation

[Installation instructions](https://nationallibraryofnorway.github.io/warchaeology/getting-started/installation)

## Documentation

Usage information is available with the help command:

    warc help

Complete documentation can be found [here](https://nationallibraryofnorway.github.io/warchaeology/)

See the [capture indexing and serving guide](docs/guides/capture-indexes.md) for
`warc index`, database and zipnum serving, and pywb replay configuration.

See the [yearly preservation guide](docs/guides/redupe.md) for `warc redupe`:
audit and rebuild self-contained yearly collections while accounting for every
input record, then generate each year's replay index with `warc index`.
